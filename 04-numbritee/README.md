# 04 – Numbritee

Brauserimäng NxN ruudustikul (N = 5–8): tõmba üks katkematu tee, mis ühendab numbrid kasvavas järjekorras ja läbib iga ruudu täpselt ühe korra. Mäng loeb aega, tagasivõtteid ja vihjeid.

Staatus: spetsifikatsioon valmis, kood veel puudub.
